# Diamonds and Dimes

**Luxury in Every Choice. Quality in Every Purchase.**

Diamonds and Dimes is a premium e-commerce marketplace developed as a collaborative React project.

## Project Overview

The application will provide product browsing, search, filtering, product details, shopping cart, wishlist, checkout, and order management features.

## Technology Stack

- React
- Vite
- JavaScript
- Tailwind CSS
- React Router
- JSON Server

## Collaboration

Team members contribute through individual feature branches. Changes are submitted through pull requests and reviewed before being merged into the main branch.
