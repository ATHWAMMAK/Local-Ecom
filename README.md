# Diamonds and Dimes

**Luxury in Every Choice. Quality in Every Purchase.**

Diamonds and Dimes is a premium-styled general e-commerce marketplace being developed as a React Single Page Application (SPA). The marketplace is intended to support product discovery, search and filtering, product details, cart and wishlist management, simulated checkout, and order tracking.

## Brand and design
- Rich black: `#0B0B0B`
- Gold: `#D4AF37`
- Champagne: `#E8D5A3`
- Warm ivory: `#FAF8F3`
- Charcoal: `#222222`

The visual identity is premium and elegant while the catalogue covers general product categories.

## Technology
- React + Vite
- JavaScript
- Tailwind CSS
- React Router DOM
- React Hooks and Context API
- JSON Server (simulated backend)
- Jest and React Testing Library
- Git and GitHub

## Main features
- Home page and product catalogue
- Product search, category filtering and sorting
- Dynamic product detail routes
- Shopping cart and wishlist
- Checkout demonstration and order creation
- Customer account and order tracking views
- Contact and support page
- Responsive layout

## Getting started
Installation and run commands will be added after the team creates the Vite project and agrees on dependency versions.

The intended development workflow will include installing dependencies, starting the Vite development server, and running JSON Server against `db.json`. Exact commands and ports must match the final `package.json`.
